# Smart Leader AI Assistance - Frontend

This is the Next.js frontend web interface for the Smart Leader AI Assistance project.

For full project setup instructions including Backend and Database setup, see the root [README.md](file:///c:/Users/hp/Desktop/smart%20leader%20AI%20assistance/README.md).

## Quick Start

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Environment Setup**:
   Create a `.env.local` file based on `.env.example`:
   ```env
   NEXT_PUBLIC_API_URL=http://localhost:5000/api
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

   Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Library**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
